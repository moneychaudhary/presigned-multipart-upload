# Security

Please report a vulnerability privately, through GitHub's
[security advisories](https://github.com/moneychaudhary/presigned-multipart-upload/security/advisories/new),
rather than in a public issue. You will get an answer within a week.

In scope: anything that lets a browser upload where, or as much as, the server
did not intend — signing for another user's key, getting past `authorize`,
`maxSize` or `allowedTypes`, or reading another user's resume records — and
anything that exposes credentials or bucket details to the browser.

Only the latest release is supported.
